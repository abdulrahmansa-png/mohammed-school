# مدرسة محمد

موقع تعليمي تفاعلي لطالب في الصف الثاني الابتدائي، مبني على كتب وزارة التعليم (طبعة ١٤٤٨هـ):

- **الرياضيات:** الفصل الأول (القيمة المنزلية حتى ١٠٠)، والفصل الثاني (طرائق الجمع)، والفصل الثالث (طرائق الطرح). ٢٠ درسًا.
- **الإنجليزي:** كتاب We Can! 2، المقدمة والوحدات ١–٣. ١٣ درسًا بنطق إنجليزي.

كل درس فيه شرح تفاعلي، ونشاط خاص به، وتدريب على ثلاثة مستويات، واختبار مع تقرير بالمهارات. وفيه أيضًا مراجعة يومية، وسباق حقائق الجمع والطرح، وصفحة لولي الأمر.

الموقع ملف واحد (`index.html`) بلا أي أدوات بناء. يُحفظ التقدّم في متصفح الجهاز نفسه.
